Web Technologies

HTML

HTML is a coding language used to create web pages.
It stands for Hypertext Markup Language.
HTML is also the foundation for web pages all over the internet.

CSS

CSS is a coding language used to define the layout or formatt of a document written like HTML.
CSS stands for Cascading Style Sheets.
Web browsers use CSS to draw things on the screen, paper, and etc.

JavaScript

JavaScript is another coding language that is a core technology for the World Wide Web along with HTML and CSS
It provides interactivity and dynamic behavior, allowing webpages to include images. graphs, maps, etc.
JavaScript brings the web page to life while CSS and HTML structures and designs the layout.
